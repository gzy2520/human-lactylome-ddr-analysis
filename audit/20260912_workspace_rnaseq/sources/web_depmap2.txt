# How can I obtain DepMap cell lines?

Resources Commonly Asked Questions

Samantha_Stokes November 17, 2024, 8:20pm 1

DepMap commonly provides the sources of cell lines used for data generation found on the portal.

Cell lines may either be purchased through commercial vendors or be donated by academic labs across the world.

To determine where you can obtain a cell line:

  1. Search the cell line and reference the Source and Source Details information in the metadata box on the top left corner of the page.
  2. Download the Model.csv file and reference the Source and Source Details columns provided.
