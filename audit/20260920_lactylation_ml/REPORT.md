## 1. 先回答老师的四个优先问题（基于可审计证据，而非模型）

- **代谢表达特征是否比简单基线提供额外预测信息？——无法回答。**
  乳酸轴表达矩阵本地缺失（服务器-only）；跨研究 Kla 标签不可比；正式训练被 7 道
  闸门全部阻断（`training_gate.csv` 全 FAIL）。任何“增量信息”数字在当前条件下
  都是伪造。
- **加入调控因子后是否进一步改善？——无法回答。** 同上。调控因子 qsmooth 值本地
  仅 28 材料聚合（`regulator_rna_qsmooth_28materials.csv`），且 qsmooth 为跨 28 参考
  联合拟合产物，不能作为前瞻预测主流程（G7 FAIL）。
- **性能能否在未参与训练的研究/材料上保持？——验证设计上不可行。**
  31 行按“共享 ReferenceKey 或共享 PXD”连通后仅 **19 个连通分组**
  （`connectivity_groups.csv`；规模谱 1,1,2,1,1,1,2,2,1,4,5,1,1,1,2,1,1,2,1）。
  多数组为 n=1；留研究/留材料验证的折标签分布无法保证（G3 FAIL）。
- **哪些信息缺失限制了解释与应用？——见 §5 数据补充清单。**
  最缺：①实测乳酸；②同一样本 RNA/蛋白/Kla 配对；③同一样本总蛋白校正分母；
  ④可比的定量 Kla 标签（强度/占有率）；⑤独立队列。

模型结果不用于证明因果关系、代谢通量或稳态。本报告未修改任何既有论文图显著性。

## 5. 最需要补充的数据（按优先级）

1. **实测乳酸**（与 RNA/蛋白/Kla 可对应的同一样本/同条件测量；任务 C 的唯一合法标签）。
2. **同一样本 RNA + 全蛋白 + Kla 富集三模态配对**（至少覆盖多个研究/材料；消除外部参考 linkage 降级）。
3. **同一样本总蛋白校正分母**（逐样本 proteinGroups 定量；否则任何“校正比例”标签无分母）。
4. **可比的定量 Kla 标签**（校准后的修饰强度或位点占有率；跨研究可比协议；否则连续标签禁行）。
5. **位点级统一坐标 + 检测背景**（任务 B2 前提；未测量禁编码阴性；阳性清单需 PU 学习设计）。
6. **独立验证队列**（未参与训练的研究/材料；预先冻结分组清单）。
7. **乳酸轴表达矩阵本地可用化**（服务器 28 矩阵同步 + Ensembl 冻结清单；当前特征字典中该行状态为“未冻结”）。

## 6. 方法学审计发现（描述性，非预测性能）

- Kla 检出数 vs log10(全蛋白检测深度)：Spearman ρ=0.189，p=0.308（n=31，无显著单调关系；
  但深度跨度 2193–14022 本身即否定“统一连续标签”假设）。
  见 `audit_detection_confounding.csv` + `fig_audit_detection_confounding.{png,pdf}`（逐图源数据同目录）。
- 按 Category 汇总：每类中位数 Kla 527–1798，但每类内 PXD 各不相同，研究与材料效应不可分
 （`audit_by_category.csv`）。
- 同一样本配对覆盖：21 行 / 3 PXD / 5 组（`audit_matched_coverage.csv`）。
- 调控因子 RNA 跨 28 参考分布：49 role 条目（48 regulators），每基因中位数/极差见
  `audit_regulator_spread.csv`（描述性；禁作训练输入）。
- 模拟隔离区（`simulation_quarantine_DO_NOT_REPORT/`）：合成 19 组（规模谱与真实连通一致）、
  固定 λ=1 岭回归分组 LOGO 流程跑通；数字仅证明代码无跨组泄漏，**不是研究结果**。

## 9. 最终结论（面向老师）

- 当前数据能预测什么？——**什么都不能作为预测模型交付。** 能交付的是：任务可行性判定、
  观察合同、连通分组、混杂审计与补充数据清单。
- 相比基线是否存在稳定增量信息？——**不可估计。** 训练禁行使任何增量数字无意义。
- 能否推广到未见研究/材料？——**验证不可行。** 19 连通组、多 n=1 组，无独立验证条件。
- 主要结果是否可能来自检测差异或泄漏？——**是。** 共享参考（HCT116 ×3、HK-2 ×2）、
  跨 PXD 材料复用与检测深度跨度是主要泄漏/混杂来源；随机拆行必泄漏，故禁行。
- 最需补充什么？——实测乳酸、同一样本三模态配对、同一样本总蛋白、可比定量 Kla 标签、独立队列。
