# 逐 RNA 样本的预测图（2026-09-26）

本次回到直接样本训练，补全逐样本结果展示。复用 2026-09-25 已完成的四个样本级岭回归模型；不重新选取更好看的模型、不改变标签、不调整来源留出划分。此前训练 R²=0.909 属于材料分布核模型，不属于这里的任何一个样本模型。

## 先看这两张

1. `outputs/20260926_individual_sample_predictions_final/figures/SampleBalanced128_sample_scatter.pdf`：每个面板有 1,898 条 RNA 记录，左边训练拟合，右边整来源留出。横轴是赋给该样本的材料占比标签，纵轴是该样本预测占比。点接近斜虚线代表与共享标签接近；同一横坐标的竖列是共享标签造成的；精确重叠会遮挡部分点。没有横向抖动或抽样。坐标统一为 0–40%。
2. `outputs/20260926_individual_sample_predictions_final/figures/SampleBalanced128_material_distributions.pdf`：每行一个材料，蓝点是逐样本预测，红菱形是该材料共用的实测标签，箱体是样本预测的四分位范围。蓝点越靠近红菱形，标签拟合越好。n 为 RNA 记录数。

每张图均有同名 PNG。`SampleMaterialBalanced` 开头的图提供此前材料等权 16 模块模型的对照；另保存来源等权 16 模块和不加权 16 模块的图，共四个模型、八张图。

## 输入及计算

主图直接输入每个样本的 128 个 Ensembl 基因表达，1,898 行参与训练，没有预先汇总为 28 行。其他三个模型把同一样本的 128 个基因转成 16 个模块分数，仍是 1,898 行训练。蛋白信息只提供共享标签，不作为 RNA 特征。来源等权/材料等权处理沿用此前供者记录分摊权重；14 个来源块不变。

训练拟合重新构建之前保存的全数据模型，惩罚参数沿用原规则：外层折所选惩罚的中位数。所有 112 个“模型×材料”训练汇总值与冻结结果一致（差异 <1e-10）。留出预测直接读取之前保存的逐样本原始分数，不重新调参。逐样本显示值限制为 0–100%；同时保留未经限制的 RawPrediction。

下表是**每份材料总权重相同**时，逐样本预测相对共享标签的 MAE，单位为百分点。先逐样本计算绝对误差再加权，并非先汇总样本预测再计算材料误差，因此不一定等于旧的材料级 MAE。

| 模型 | 训练拟合 | 来源留出 |
|---|---:|---:|
| 128 基因，来源等权训练（主图） | 8.41 | 9.47 |
| 16 模块，材料等权训练 | 8.00 | 8.55 |
| 16 模块，来源等权训练 | 7.83 | 9.16 |
| 16 模块，样本记录等权训练 | 7.20 | 9.83 |

这些分数描述“预测与共享材料标签的一致性”，不是对每位患者真实占比的准确率。图中可见主模型预测集中在中间区间，低标签材料被高估、高标签材料被低估；更换为逐样本作图并没有带来先前材料核模型的高拟合成绩。
