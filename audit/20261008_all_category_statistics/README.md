## 统计方法与结果

沿用来源平衡类别均值模型、来源聚类 CR2 标准误和 Satterthwaite 自由度。每一来源与类别的总权重为 1。蛋白组按实际 SourceFile 中的 PXD 聚类；RNA 按冻结 ConnGroup 聚类。MKI67 比值在 log10 尺度检验，与既有图的分析尺度一致；其余指标使用图中相应原始占比或冻结 RNA 得分尺度。

蛋白组占比检验去除复用参考，保留 269 条推断记录；图中仍保留原有 272 条显示记录。七通路使用 504 条样本与通路记录，Pro/Inh 分别检验。RNA 使用 28 份去重材料，不能把它们理解为 28 名独立患者。图上 n 为显示记录数；检验的记录数和来源数随表给出。

BH 校正族分别为蛋白组 DDR 占比 6 次、七通路 42 次、三个 MKI67 比值 9 次、RNA DDR 检出基因占比 3 次。DDR 表达单图沿用之前双基因集图的 6 次校正结果，没有因拆成单图重新缩小校正范围。重复展示同一指标不算新增独立证据。

图例：ns 为 q ≥ 0.05；* 为 q < 0.05；** 为 q < 0.01；*** 为 q < 0.001；**** 为 q < 0.0001；NE 为零变异或对比无法估计，没有有效的 P/q，不能解释为不显著。10 个通路对比为 NE，BH 校正仍按全部 42 个预设对比计数。

本次 60 个新增或更新的对比中，50 个可估计，5 个 q < 0.05：

- 普通蛋白组 DDR 占比：肿瘤组织对正常细胞系、癌细胞系，q 均约为 0.0100。
- Kla DDR 占比：肿瘤组织对正常细胞系，q 约为 0.0100。
- RNA DDR 检出基因占比：肿瘤组织对正常细胞系、癌细胞系，q 均约为 0.0414。

其余可估计对比为 ns。完整 P、q、差值、置信区间、自由度、记录数和来源数见统计 CSV。MKI67 的非肿瘤组织只来自一个研究来源，相关推断的外推范围尤其有限。来源聚类不消除治疗、组织组成和检测深度等混杂，也不把跨研究结果变成因果结论。

## 其他图的逐项处理

完整包中每张当前图均列入 `逐图统计处理清单.csv`，明确本次替换、沿用已完成统计、保留描述或不适用。没有把所有柱状几何图形都视为具有重复观测的分组实验。

- S1 按 PXD/具体材料排列的箱线图、RNA 按 28 份具体材料排列的条形/箱线明细：横轴不是四个类别，不能把类别检验的横线连到某一任意材料。对应类别汇总图已补齐统计；这些明细图保留原值，未新增材料两两检验。
- 乳酸代谢 Focus 和 LDHA/LDHB 样本分布图：展示具体肝脏、前列腺或 28 份材料，不能把不同器官中的癌组织合并成一个未定义的对照。原始供者与配对关系未在本次重新审定，仍作为描述图，未开展新的材料级差异检验。
- 乳酸代谢蛋白检出数量柱图：为材料汇总/并集计数，不存在可据以计算该对比误差的独立重复。
- 机器学习图（包括预测值的分类箱线图、误差分布柱图）：预测值不是新增的独立生物学实测，保留既有测试集 MAE、R² 等评价，不对它们套生物学类别显著性横线。
- 热图、UpSet、重要性、UMAP、机制图及描述性差值图不使用这类比较横线。

因此，本版完成的是全部 15 张四类别生物学汇总图的统计标注。上述材料明细图没有新增统计，清单明确列出，不能宣称全部带柱形或箱形的图均已完成推断检验。
