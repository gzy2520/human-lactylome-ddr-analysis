# 图二 RNA：以肿瘤组织为参照的统计标注

本版按最新要求，在两个 RNA 单图上补充以肿瘤组织为参照的组间比较横线。旧的 20261007 无横线版本保留；不组合面板，不重跑 RNA 矩阵或机器学习。

## 图形与数据

- Figure_2a：蓝色为 DDR 基因集，橙色为已检出乳酸化蛋白对应基因集的 RNA 表达。两套基因集分别比较；共 56 个材料与基因集组合点、8 个箱体。
- Figure_2b：Hallmark G2M Checkpoint 的 RNA 增殖相关转录评分，共 28 个材料点、4 个箱体。该评分不是实测增殖速率。

均读取 `outputs/20260919_repair_release/core` 的冻结表。四类顺序仍为非肿瘤组织、肿瘤组织、正常细胞系、癌细胞系；材料数为 9、3、6、10。HCT116、HK-2 复用参考已去重。横轴 n 为 RNA 材料数，不是独立患者数。

左图先在每条 RNA 记录内取对应基因集的变换后表达中位数，再取材料内 RNA 记录的中位数。右图先在每条 RNA 记录内取冻结的 196 个 Hallmark 基因的变换后表达均值，再取材料内 RNA 记录的中位数。表达变换为 log2(qsmooth TPM + 0.5)。乳酸化蛋白对应基因的 RNA 表达不是蛋白乳酸化占比、修饰强度或占据率。

箱体为四分位间距，黑线为中位数，须线按 1.5 倍四分位距规则；红线为类别内材料点的未加权均值。所有点均保留，包括箱体外的点。无背景网格。每张图 4 × 4.1 英寸，PNG 为 600 dpi，同时提供 PDF、SVG。

## 统计横线

参照组固定为肿瘤组织，分别与非肿瘤组织、正常细胞系、癌细胞系比较。左图在 DDR 和 Kla 蛋白对应基因集内分别检验，共 6 条横线；横线和 ns/星号颜色与相应基因集一致。右图为 3 条横线。

沿用已有来源平衡模型：同一来源块与类别的材料点总权重为 1，采用来源块聚类的 CR2 标准误和 Satterthwaite 自由度。来源块由 `sample_metadata.csv` 中的 ConnGroup 定义，以保留同来源及共享供者连接的依赖。模型使用全部四类材料；估计值为“比较类别 − 肿瘤组织”的来源平衡均值差。图中箱体和红线描述未加权材料点，与模型均值口径不同。

本版改变了预先指定的比较集合，不能直接沿用旧图的 q 值：左图 6 次检验统一作 BH 校正，右图 3 次检验单独作 BH 校正。校正后的 q 用于标注：ns 为 q ≥ 0.05，* 为 q < 0.05，** 为 q < 0.01，*** 为 q < 0.001，**** 为 q < 0.0001。具体 P、q、差值、标准误、自由度和置信区间见数据表。

本次左图 q 为 0.676–0.949，右图三个 q 均约为 0.252，均标 ns。这表示这些检验未达到设定阈值，不能解释为已经证明类别相同。肿瘤组织只有 3 份材料；来源聚类无法消除治疗条件或跨研究混杂。

本次“图二”是当前论文排版编号，源表名仍为 Figure_1a/1b，与旧的 UpSet/通路 Figure_2 不是同一组面板。
