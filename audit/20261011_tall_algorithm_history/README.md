# TALL DDR占比：最早柱图、样本图与两次重建的对照

## 结论

最早可验证柱图的TALL乳酸化占比是 **37/368＝10.054348%**。它合并富集与非富集两部分的乳酸化鉴定，按材料去重计数，没有样本均值或误差线。原来截图中的 **1.790561%** 来自后续样本化代码的混合计算。上一轮重建的 **12.707291%** 又因PEAKS多accession冒号拆分遗漏而高估。完整复现原解析器后，当前富集三个样本的均值为 **11.421069%，SEM 0.521117个百分点**。

## 四套算法

设D为冻结GO-DDR蛋白集合；Oᵢ为样本i中protein Area>0的全部富集检出蛋白；Lᵢ为样本i直接鉴定Lac PSM经完整肽段/蛋白位置映射得到的乳酸化蛋白；K为最早流程两臂全部样本乳酸化蛋白的并集。

|版本|分子与分母|如何汇总|TALL Kla占比|
|---|---|---|---:|
|最早可验证柱图|K∩D的蛋白数 / K蛋白数；37/368|富集和非富集全部入选鉴定合并去重|10.054348%|
|后续样本图|Oᵢ∩K∩D的蛋白数 / Oᵢ蛋白数|三个样本比例算术平均|1.790561%|
|上一轮重建|遗漏多accession后的样本Lac集合及其DDR交集|三个样本比例算术平均|12.707291%|
|本次完整复算|Lᵢ∩D的蛋白数 / Lᵢ蛋白数|三个富集样本比例算术平均|11.421069%|

1.79%首次可由实际输入CSV验证于提交`6735dc8`。更早的`4239155`虽然已引入样本图流程，TALL仍是368/37的dataset_union；随后新增的TALL按protein Area拆样本与原冻结Kla标签连接，才产生29/1662等数值。对应Git代码差异及CSV已保存在`earliest_barplot/`。

### 原1.79%的问题

`read_tall_by_sample()`只以proteins.csv的Sample Area>0选分母，没有要求当前样本的Lac鉴定；随后把组级Kla membership中的IsDdr连接到这些蛋白，未匹配者写为FALSE。因此，分母约1660个一般富集检出蛋白，分子却是组级乳酸化DDR集合的交集。若只修补所有蛋白的GO注释，会得到114/1662、112/1686、117/1678，均值6.824911%；它描述的是富集表全部检出蛋白的DDR比例。

按当前raw的乳酸化证据同时重建分子、分母后，分母约200。原29/30/31分子中的部分蛋白只在其他样本或非富集臂有Lac证据，不能凭当前样本一般protein Area给它们增加Lac检测。另一方面，某些蛋白在当前raw有Lac PSM但protein Area为0，因此完整新集合也有原集合外的新增蛋白。每样本的增删及PSM源行号均见`sample_comparison/`。

### 上一轮12.71%的问题

TALL富集PSM有72条多accession记录用冒号分隔。原`accession_candidates()`按`[;:]`拆分；上一轮独立复算按`[;,]`拆分，再截去竖线后的注释，漏掉了后续accession。每样本因此少计23、23、22个蛋白，样本2还少计1个DDR（P26583）。本次直接调用原`extract_pxd028488()`，并由独立R完整拆分实现核对，595条样本-accession记录完全一致。

上一轮20项验证主要核对已重建membership与图表的一致性，没有检出该源解析错误；本次增加了原始解析器与独立实现的逐accession集合对照。12.71%版本保留为历史，当前图另存为`deliverables/20261011_lactylation_ddr_tall_verified/`。

## 最初图为何是10.05%

原始解析器在当前原表上可精确重现最初冻结集合：

|乳酸化鉴定范围|去重蛋白|DDR蛋白|组并集比例|
|---|---:|---:|---:|
|富集臂|257|30|11.673152%|
|非富集臂|162|10|6.172840%|
|两臂共有|51|3|—|
|两臂合并|257＋162−51＝368|30＋10−3＝37|10.054348%|

11.42%与10.05%的剩余差异来自两点：样本比例均值与组去重并集是不同汇总统计量；当前样本图只使用富集三个raw，最初图还纳入非富集臂的Lac鉴定。保留最初统计量时使用37/368；要画富集三个来源观测的误差线时使用完整样本值及11.421069±0.521117%。目前没有用相同末尾编号直接把两臂假定为配对样本。

## 历史证据与筛选条件

最早证据是主仓库根提交`e5a89ac`保存的报告（文内日期2026-08-05）和实际脚本；最初10模型图的TALL Kla已经是37/368。该版本whole背景是TALL-1替代来源267/3383＝7.892403%；后续`372651b`只更换whole背景为同研究TALL非富集蛋白组。更早2026-07-21归档在旧脚本中有引用，但当前未找到可验证结果。Git快照、原始路径及哈希见`earliest_barplot/`。

本次逐样本复算保留原PSM解析规则：-10lgP≥20，排除decoy/contaminant，识别Lac位置并校验肽到accession的位置映射。额外应用原论文AScore≥20定位阈值时，完整accession结果为15/161、21/169、18/165，均值10.883966%，作为敏感性结果单列。当前图没有单独改变TALL的定位筛选阈值。
