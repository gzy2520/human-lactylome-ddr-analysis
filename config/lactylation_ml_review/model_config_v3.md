# 冻结：B-R v3 模型比较配置与数据契约（2026-09-21）
# 任务 B-R：行=(GroupID, DDR蛋白)|RefDetected；y=该流程下Kla检出；19连通分组留一。种子25。
# 标签为流程检出结果；不称浓度/位点占有率/生物学真值。

## 1. 分析对象与数据契约
- 任务：已知DDR蛋白在未见连通分组（ConnGroup）材料中的Kla流程检出预测。
- 行定义：DDR蛋白 × 材料（GroupID），背景为Ref检出（RefDetected == TRUE）。
- 规模：6,744行，2,708正例（正例率40.15%），19个共享来源连通组，31个GroupID，28个ReferenceKey（HCT116有3个GroupID共用RNA参考，HK-2有2个GroupID共用RNA参考）。
- 稳定标识符：蛋白使用 BaseAccession（UniProt），基因使用 EnsemblGeneID；不以易变 Gene Symbol 作为主键。
- 相同评价集合：全部模型使用完全相同的6,744行评价对象。

## 2. 模型清单与归因框架
为实现严密归因，避免将校准或表达变化混淆为机制模块增量，定义如下对照模型：

| 模型代号 | 特征定义 | 拟合框架 | 归因角色 |
|---|---|---|---|
| **M0** | 无特征 | 训练折总体正例率常数预测 | 下界常数基线（每折ROC=0.500，AP=折内正例率） |
| **MP** | 训练折Ref背景蛋白检出频率 | Beta(1,1)平滑直接输出，未见蛋白回退M0 | 蛋白固有检出倾向启发式基线（无回归拟合） |
| **MP_cal** | 交叉拟合z_mp特征 | 逻辑回归 + L2正则（与组合模型相同框架） | 可校准MP-only模型（检验MP经回归校准的效果） |
| **ME** | z_target_expr | 逻辑回归 + L2正则 | 目标表达基线（无机制模块，无MP） |
| **ME2** | z_target_expr + z_mod | 逻辑回归 + L2正则 | 目标表达 + 乳酸生成模块（检验无MP时的模块增量） |
| **ME_P** | z_target_expr + z_mp | 逻辑回归 + L2正则 | MP + 目标表达（关键对照：与ME2P完全对齐但无模块） |
| **ME2P** | z_target_expr + z_mod + z_mp | 逻辑回归 + L2正则 | MP + 目标表达 + 乳酸生成模块（检验组合模型） |
| **XEN** | z_target_expr + z_mod + z_ix | 逻辑回归 + L2正则（z_ix = z_target_expr * z_mod） | 交互探索模型 |

### 关键归因对照逻辑：
1. 模块净增量：必须在同构回归框架下比较 **ME_P** 与 **ME2P**（均含z_target_expr和z_mp，唯独增减z_mod）。
2. 无MP背景下的模块净增量：比较 **ME** 与 **ME2**。
3. MP回归校准效应：比较原始启发式 **MP** 与回归校准后的 **MP_cal**。
4. 表达对MP的净增量：比较 **MP_cal** 与 **ME_P**。

## 3. 正则化与优化契约
- 候选网格：$\lambda \in \{0.05, 0.1, 0.3, 1.0\}$。
- 目标函数：负对数似然和 + L2罚项（非截距系数）：
  $$J(\beta) = -\sum_{i=1}^n \left[ y_i \ln p_i + (1 - y_i) \ln (1 - p_i) \right] + \frac{\lambda}{2} \sum_{j=1}^p \beta_j^2$$
- 优化方法：Newton-Raphson / IRLS。
- 健壮性规则：
  - 若 `solve(A, b)` 奇异或产生非有限值，立即捕获并标记 `failed = TRUE`，记录错误信息，不更新系数，不得宣称收敛。
  - 达到最大迭代次数（maxit=200）未达容差（tol=1e-8）标记未收敛。
  - 权重下溢检测：记录 `irls_weight_underflow_detected`，明确区分数值收敛与无分离假设。
- 参数选择规则：所有正则化模型统一在内层5折连通分组交叉验证中，以**等权LogLoss最小化**为准则选取最佳 $\lambda^*$。

## 4. 严格内层隔离与特征工程契约
- 材料级基因中位数：由UNSMOOTHED log2TPM逐材料计算，仅为材料内样本聚合，不依赖训练/测试划分。
- 机制模块：冻结乳酸生成模块 `mact_generation_lactate`（LDHA, LDHB, LDHC, LDHAL6B, LDHD），取成员基因材料中位数均值，方向不加符号。
- 标准化与填补：
  - 材料级模块特征 $z_{\text{mod}}$：由训练集合中不重复参考材料（每材料权重1）估计均值和标准差。
  - 蛋白×材料特征 $z_{\text{target\_expr}}$：使用材料等权加权统计（每材料总权重相等，各行权重为其所在材料行数倒数），保持蛋白级真实尺度与方差，严禁压缩为单材料单一中位数。
  - MP特征 $z_{\text{mp}}$：由训练集交叉拟合MP频率的均值和标准差标准化。
  - 缺失填补：在原始尺度由训练集统计量填补后再行标准化（本次DDR实测缺失率为0）。
- 内层隔离流程（对外层训练集 $T$）：
  1. 将 $T$ 包含的连通组划分为5个内层折。
  2. 对内层验证集 $V = T \cap \text{fold}_f$ 与内层训练集 $A = T \setminus \text{fold}_f$：
     - 标准化参数仅由 $A$ 拟合。
     - $V$ 的MP频率仅由 $A$ 的标签估计（若未见蛋白回退 $A$ 的平滑总体率）。
     - $A$ 内部用于拟合模型的MP特征，必须在 $A$ 内部再次按连通组留出交叉拟合，严禁接触 $V$ 标签或行自身标签。
     - $V$ 的标签仅用于内层验证评价与 $\lambda$ 选择，绝不参与任何训练输入。
  3. 选定最佳 $\lambda^*$ 后，在全部 $T$ 上重新交叉拟合训练MP特征、拟合预处理和最终模型。
  4. 外层测试集 $E$ 的MP频率与特征变换，完全由 $T$ 的统计量决定；$E$ 的标签在预测完成前绝对不可见。

## 5. 评价指标与汇总口径
- 主指标：外层留出（19连通折）**等权均值 LogLoss**（各折等权，以折为独立评价单元）。
- 副指标：
  - Brier 分数（等权均值）。
  - AP（阈值聚合版，并列块以块末行累计TP聚合，严格行序不变；区分于梯形PR-AUC）。
  - PRAUC_trap（梯形积分PR-AUC，单独命名与报告）。
  - ROC-AUC（每折评价；M0折内恒为0.500）。
  - 材料级校准：按28个 ReferenceKey 汇总（及31个 GroupID），计算预测均值与观察正例率的平均绝对误差（MAE）。
- 辅助参考口径：
  - 样本量加权均值（n_weighted）。
  - 全数据 pooled 指标（仅供参考，明确标注 pooled_reference_only，禁用跨折常数比较的 pooled ROC）。
- 敏感性分析：
  - S1：评价汇总敏感性（留一测试折重新计算剩余折等权均值，不重训）。
  - S2：真实训练敏感性（真正剔除一个连通组后，在剩余18组上完整重跑外层验证，含内层调参和隔离，与原模型在相同剩余18组上进行成对差值比较）。
