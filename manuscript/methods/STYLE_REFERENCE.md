# Methods writing reference

## Reference article

Hu Y, Xie M, Li Y, et al. Benchmarking clustering, alignment, and integration
methods for spatial transcriptomics. *Genome Biology*. 2024;25:212.
doi: [10.1186/s13059-024-03361-0](https://doi.org/10.1186/s13059-024-03361-0).
PMCID: [PMC11312151](https://pmc.ncbi.nlm.nih.gov/articles/PMC11312151/).

## What was borrowed

The reference article separates its Methods into:

1. data and method overview;
2. quantitative analysis and explicit metrics;
3. qualitative analysis and visualization;
4. computation platform;
5. data and code availability.

The current Kla project Methods use the same organizational logic:

1. public data acquisition and eligibility;
2. dataset-specific Kla evidence extraction;
3. stable protein identifier harmonization;
4. exact whole-proteome reference pairing;
5. explicit DDR fractions, percentile equations, and Venn membership rules;
6. visualization, quality control, software, and reproducibility.

No sentence, benchmark metric, or spatial-transcriptomics algorithm was copied
into the Kla Methods. The reference was used only as a model for ordering
information and reporting reproducible computational decisions.
