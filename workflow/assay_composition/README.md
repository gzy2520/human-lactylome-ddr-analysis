# 图 1a 口径的四目标 RNA 预测（2026-09-29）

## 目的与标签

本轮按导师更正的目标重新训练四个模型，输入仍为全转录组共有的 18,332 个 Ensembl 基因。输出为：

1. Proteome_DDR：普通蛋白组中 DDR 蛋白数 / 该普通蛋白组全部蛋白数。
2. Kla_DDR：Kla 蛋白组中 DDR 蛋白数 / 该 Kla 蛋白组全部蛋白数。
3. Proteome_DNA_repair：普通蛋白组中 DNA repair 蛋白数 / 全部普通蛋白数。
4. Kla_DNA_repair：Kla 蛋白组中 DNA repair 蛋白数 / 全部 Kla 蛋白数。

全部乘 100，以百分比建模。分子与分母来自同一组学，不求普通组和 Kla 组交集，不计算两组学之间的比值。标签是检出蛋白种类的组成比例，不是表达强度、修饰强度或位点占有率。

## 冻结输入与计数

GO 集合沿用冻结的人类注释：DDR 2,660 个 BaseAccession，DNA repair 2,135 个。GO 层级沿用 is_a / part_of。普通组保留 publication_input 的 SourceProteinID 计数单位（包括 Ensembl protein），映射仅用于判定 GO 成员；一个源 ID 对应多个 UniProt 时，任一映射命中即计入，但源 ID 只计一次。Kla 以去重 BaseAccession 计数。肺和胎盘的源 ID 数量与合并 UniProt 后数量不同，差异已输出 identifier_sensitivity.csv，未静默替换原图分母。

31 组 DDR 的分子、分母均与冻结 group_summary_31.csv 完全一致。31 组按 ReferenceKey 对应 28 个 RNA 材料；重复材料沿用各组占比算术平均。蛋白成员与映射输出保留稳定 ID，图上若显示符号仅为辅助。

## 建模与评估

输入为既有校正后的 1,898 × 18,332 矩阵，log2(TPM+0.5)。沿用冻结划分：训练 1,524 条，内部留出 374 条（19 种材料），14 个来源关联块留出。已知供者不跨内部划分；106 条未知供者记录使用伪 ID，不能声称其身份已完全核验。来源块不等同独立实验室。内部划分和算法有开发历史，不是另行封存的盲测集。

四个模型固定 ranger 回归森林：500 树、mtry=135、min.node.size=1、seed=25、4 线程。抽样权重使材料等权、材料内供者等权、供者内记录等权。所有目标全部报告，不按外部表现调参或删除不理想结果。输出全数据拟合、训练子集拟合、内部留出和来源留出；全量模型用于外部预测。Top25 是训练子集模型在全部基因上的方差减少重要性，不是因果贡献。

主表同时报告逐记录和材料/供者等权口径。无 RNA 对照使用各次训练材料标签的中位数，不使用该次留出标签。报告 MAE、RMSE、R²、误差在 ±1/±2/±5 个百分点内的比例；±1 为本轮较窄目标范围的描述性辅助阈值，不是预先规定的成功标准。不能只凭较宽阈值内的比例判定模型成功。

## 外部比较

质谱 PXD063945 排除 NAC；按肿瘤或癌旁分别合并检出列表，普通组各 25 列、Kla 各 22 列，不构造不存在的患者跨组学配对。使用全蛋白、全 Kla 蛋白各自的分母。癌旁 Kla 的 DDR/DNA repair 分子为 42/28；不再因其中一个蛋白未在普通组检出而排除它。

GSE130078 为 23 位患者的 46 份配对组织 RNA，与训练样本 ID 不重叠。其 log2(TPM+0.5) 输入已从原始计数重建；临床治疗前史不完整。每个目标只有肿瘤、癌旁两个外部材料标签，不是 46 个患者级质谱真值。另保留 95 条既有 TCGA ESCC RNA 对新质谱标签的比较，明确这是复用训练 RNA，不能作为独立外部 RNA 测试。

## 运行与产物

脚本目录 workflow/assay_composition；输出隔离在 outputs/20260929_assay_composition。原始数据和旧报告保留。

- labels.R：新标签、逐蛋白成员、与图 1a 的计数核对。
- external_labels.R：外部质谱组学内标签。
- train.R：参数为 RNA 输入目录、全新模型输出目录、目标名；四个目标各运行一次。
- predict_external.R：参数为 RNA RDS、全新输出目录、newRNA 或 reused_TCGA。
- summarize.R：独立重算指标、核对划分与成员、对照基线、生成四目标概览图。
- report.py：从本轮结果生成中文报告，不引用上一轮指标。

依赖：R 的 data.table、ranger、ggplot2、ragg、readxl、digest；Python 的 python-docx。每个模型保存 sessionInfo、输入哈希及逐记录预测。R 使用 --vanilla 以调用本机已安装依赖，避免自动启用未恢复的旧 renv 库。使用新目录启动，避免混入旧结果。
